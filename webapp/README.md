# Windows 本地商品工作台

## 启动

安装 Python 3.10 或更新版本（勾选 Add Python to PATH），在项目根目录双击 `启动工具.bat`。
首次启动自动创建 `.venv`，安装 `webapp/requirements.txt` 和 Playwright Chromium，需要网络。
服务固定监听 `127.0.0.1:8765`，健康检查成功后打开浏览器。关闭终端或 Ctrl+C 停止服务。
如果浏览器没有自动打开，可手动访问 `http://127.0.0.1:8765`；端口占用、安装失败等会在终端显示。
不要将本服务改成公网监听或经反向代理公开。

## 使用

1. 平台账号 → 打开登录窗口 → 在本机浏览器扫码/完成验证。
2. 商品采集 → 输入逗号分隔关键词、平台和页数 → 开始采集。
3. 进度显示实际完成的关键词/平台工作单元，不代表页内进度。原爬虫没有页级进度接口。
4. 每次采集结果按平台和商品 ID 更新，只保存信息、介绍和图片地址。需要保存图片文件时，选择商品或图集中的图片后单独点击下载。
5. 商品卡片/表格支持当前页全选、跨页选择（筛选时清空选择）、下载选中、CSV/ZIP 导出。
6. 加入待发布后编辑独立草稿，再在发布中心选择平台和校验资料。

闲鱼新增商品详情图集与描述采集；淘宝也支持详情图集补采，轮播、SKU、详情图按实际来源分类。未明确分类的闲鱼商品图不伪装成 SKU 图。图片 CDN 白名单为 alicdn.com、tbcdn.cn、taobaocdn.com；未知域名下载失败会记录原因，不会放开任意 URL。白名单 CDN 返回的 HTTP 链接会自动改用 HTTPS 下载（只接受标准端口），不会发出明文 HTTP 请求。更新后可直接重试已有失败图片，无需重新采集。
下载限制 15 MB、2500 万像素、20 秒网络超时和 45 秒读取总时限；停止图片任务会等待当前网络阻塞返回（一般最多 20 秒）。
图片按平台/安全处理后的关键词/商品 ID/内容哈希保存。相同内容不会重复覆盖；不同商品目录保留各自文件。
CSV 做公式转义；ZIP 根目录直接按平台/搜索关键词/商品名组织，包含已下载图片、商品介绍.txt、商品信息.json 和图片清单.csv。导出不发起下载；未下载或失败图片写入清单。独立 CSV 导出仍可使用。
删除商品记录保留下载文件和独立草稿，以免误删已用于发布准备的资料。

## 数据和隐私

默认存储 `data/webapp/products.db` 和 `data/webapp/images/`；可用 `PRODUCT_TOOL_DATA` 环境变量指定其他目录。
关闭服务后复制整个数据目录可备份。账号文件仍存放在原 `state/`，不通过 Web 暴露。
Web 调用禁用爬虫原始日志/页面 dump，避免登录信息或会话 URL 写入普通日志。原 CLI 行为保持原样。
账号“已保存本地状态”不代表平台确认登录有效；实际采集可能要求重新登录、人工验证或被平台限制。

## 发布扩展

`publishers.py` 定义 Draft、TaobaoPublisher、XianyuPublisher、XiaohongshuPublisher。
统一字段：标题、描述、售价、分类、库存、SKU、图片、物流、目标平台、平台专属字段。
所有适配器均明确为“暂不支持 / 需要官方授权”，真实发布端点返回 409。
当前校验只验证基础草稿，不宣称符合各平台最终官方字段规范。
接入官方 API 时须补齐授权、平台字段规范、人工确认、结果持久化和失败处理，再启用发布。

## 图片预览与详情

商品列表上方可直接切换全部图片、已下载、可下载/待重试、下载失败和无图片。
未下载主图通过安全校验后显示在线缩略预览；预览不会改变下载状态，也不会写入本地商品图片目录。
“可下载”表示已提供主图地址，可发起下载，不保证平台一定允许访问。预览失败仍可尝试下载以查看具体失败原因。
点击图片或“查看详情”可查看大图、商品字段、下载失败原因和本地图片相对路径。
已下载图片可点击“保存图片”或详情内“保存主图到电脑”，另存到浏览器下载目录；批量另存请导出 ZIP。
详情中的图集和描述展示实际采集结果，不伪造平台未返回的信息。


## 闲鱼多图采集（本次更新）

- 新搜索：仅获取商品列表和主图地址；需要图集和描述时，再勾选商品补采详情。
- 已有商品：列表勾选 → **补采选中商品详情**。不需要重新搜索；补采完成后点击查看详情。
- 详情弹窗：展示所有已获得图片与逐图状态，可全选、勾选下载、下载全部、刷新状态、单图保存。列表会显示图集张数及已下载张数。
- ZIP 导出仅打包选中商品已下载的图片及商品资料；同内容文件在同商品目录中按哈希去重。
- 自动升级 SQLite，保留现有主图和下载路径。升级前建议关闭程序并备份 data/webapp。
- 详情采集复用已有登录状态，访问普通商品详情页面；未返回匹配图集、跳转登录、超时、下架或结构变化会标记失败，保留搜索主图，可稍后补采重试。
- “全部”指平台详情响应实际返回的商品图片，不表示能取得平台隐藏或禁止访问的图片。没有真实账号环境，当前详情解析以模拟响应、边界测试验证，真实平台完整性仍需本机实测。
- 淘宝详情图集现已接入独立适配器，操作方式相同，需先保存淘宝登录状态。


## 淘宝多图详情

新搜索仅采集淘宝商品列表；需要详情信息时，勾选商品后点击“补采选中商品详情”（不下载图片文件）。
独立适配器访问普通商品详情页面，从与目标商品 ID 匹配的详情响应提取轮播图和 SKU 图，并收集匹配的描述响应或已确认商品的描述容器中的详情图。
未获得详情图时显示“部分获取”，保留已有轮播/SKU 图片，允许重试；不会把推荐商品、店铺图标混充商品图集。
遇到登录跳转、访问限制或未知接口结构会返回失败提示，不绕过验证。可在平台账号重新登录后重试。
图集中的封面、轮播/商品图、SKU 图、详情图均支持选择下载、全部下载和 ZIP 导出。
当前验证覆盖模拟接口响应、分类持久化、懒加载回调和浏览器界面；没有在真实淘宝账号上验证图片获取完整性。


## 采集、下载、导出是三个独立操作

1. **采集**：保存搜索信息、商品介绍和图片地址；详情补采也不会自动下载图片。在线缩略预览会请求图片，但不会保存到商品图片目录或改变下载状态。
2. **下载**：选中商品后点击“下载选中商品全部图片”，或在详情内勾选具体图片下载，才保存本地图片文件。
3. **导出 ZIP**：只打包已有本地图片和商品资料，不补下载。商品介绍未采集时如实注明；未下载/失败/文件缺失列入图片清单。

ZIP 内部从根目录直接开始：

```text
闲鱼/
  机械键盘/                    # 搜索关键词，不冒充平台官方类目
    商品名字/
      001_封面.jpg
      002_商品图.png
      商品介绍.txt
      商品信息.json
      图片清单.csv
```

没有额外 data、webapp、images 包装目录。名称中的 Windows 非法字符会替换，同名商品追加内部记录编号防止覆盖。
旧版已下载的图片保留，升级不会删除它们；同样可按新目录结构导出。

## 浏览器选品、批量链接和店铺页面读取

“商品采集”页面新增“浏览器选品 / 店铺采集”区域。

1. 选择淘宝/天猫或闲鱼，点击“打开选品浏览器”。工具会打开独立 Chromium 窗口并加载该平台已有登录状态。
2. 在平台窗口浏览商品或店铺；也可在管理页面输入完整链接并点击“在选品浏览器打开链接”。不接管平时已经打开的 Chrome。
3. 如在选品窗口手动登录，点击“保存本窗口登录状态”。成功读取商品/列表时也会尝试保存已检测到的有效登录标记；仅保存到私有 state 文件，账号有效性仍以平台实际访问为准。
4. 回到管理页面选择对应标签页：
   - “读取当前商品”：把当前商品作为候选。
   - “读取当前列表页”：读取当前页面商品链接并去重。
   - “读取店铺 / 卖家主页”：在店铺页面滚动发现商品，并尝试语义明确的“下一页”按钮/链接。限制 1–10 轮、最多 200 个候选；“轮”不是平台真实分页总数。
5. 候选卡片显示名称、可用缩略预览、商品 ID 和来源页面。勾选后可仅加入商品库，或直接启动选中商品的详情采集。两者均不自动下载图片。
6. “关闭浏览器 / 停止读取”会终止选品进程及其浏览器；已发布的候选保留。

店铺页可能包含推荐商品，当前候选不宣称经过店铺归属验证，请人工核对。平台页面结构/分页不受支持时，可在平台窗口手动翻页，再点击读取当前列表页。不能保证发现隐藏、下架或平台限制访问的商品，也不绕过验证码。

闲鱼卖家页支持 `www.goofish.com/personal?userId=...`；淘宝/天猫支持店铺独立域名首页及店内列表。链接导入支持 goofish 商品页、item.taobao.com 和 detail.tmall.com 的完整商品 ID 链接；分享短链接需先在浏览器打开后复制完整地址。

“粘贴商品链接批量采集”每行一个链接，最多 200 条，所有链接校验通过后才写入商品库。重复导入不会覆盖已有商品名称、价格和已下载图片。纯链接商品先显示待采集标题，详情采集取得真实标题/图集后更新。

保存分类用于导出目录中的搜索关键词层级；来源页面名称和链接会随商品信息导出，不伪装为已验证的店铺归属。

验证：实际 Chromium 子进程搭配模拟平台页面已覆盖打开、导航、店铺候选、当前商品、勾选导入及停止。真实淘宝/闲鱼店铺页兼容性和 Windows 桌面操作仍需本机实测。

### 先列表、后详情（后台采集）

「采集商品列表」仅获取列表字段和主图地址，不再自动逐件访问详情页。完成后在列表勾选商品，点击「补采选中商品详情」获取描述和更多图片地址，再按需下载图片。重新采集列表保留已有详情和图集。

关键词搜索与详情补采使用无头浏览器在后台运行，不弹出浏览器窗口。登录和手动浏览器选品仍显示窗口；后台遇到登录失效或平台验证会提示失败，请打开登录窗口完成验证后重试，不会自动切换可见窗口或绕过验证。

浏览器选品候选卡片每 3 秒同步逐件详情状态（等待、采集中、完成、部分完成、失败）。每件商品保存后即可点击卡片上的「查看详情」，无需等待整批结束；停止任务后已完成的结果保留。

自动刷新：任务运行时每轮结束后等待 3 秒查询状态；无任务且选品窗口关闭时改为 30 秒检查。商品列表仅在任务进度或结果变化时刷新。页面隐藏时暂停自动轮询，返回页面或执行操作后恢复检查；慢请求不会叠加。选品窗口打开期间仍同步标签页，平台账号页仍定期检查登录状态。

### 登录会话复用与详情批次

- 「原始链接」「查看原商品」现在通过工具的登录窗口打开，不再跳系统默认浏览器；同平台已有窗口会在其中新建标签页，并保留候选列表。关闭后重新打开会加载保存的登录状态。
- 同平台选品窗口已打开时，详情批次借用该窗口的实际浏览器上下文，不再复制状态后逐件启动新浏览器；任务结束释放占用并保留窗口。借用期间暂不允许导航、关闭窗口或重新登录，避免干扰采集。停止/超时可能关闭正在使用的窗口，已完成资料保留。
- 没有同平台窗口时，每个平台批次只启动一个无头浏览器，所有商品共享其上下文。常规登录仍复用原登录助手；已有选品窗口时账号登录入口使用该窗口。登录文件仅保存在本机，关闭工具窗口前尝试保存刷新后的状态。
- 商品访问仍串行节流，页面加载时间计入最小访问间隔，不再每件额外固定等待。后台禁载视频和字体，保留图片、脚本和数据请求以免影响详情提取。淘宝取得匹配的完整描述响应后跳过剩余固定滚动等待，未取得时仍有限等待并如实标记部分结果。
- 登录失效或人工验证会停止后续商品访问；其余商品保持未采集，可完成验证后重新选择补采。不承诺平台永不使会话失效。采集时可看本地详情，打开原商品需先完成或停止当前任务。

会话传递、批次浏览器复用及界面操作以真实 Chromium 配合模拟页面/数据验证；尚未使用真实淘宝/闲鱼账号或 Windows 验证平台登录有效性及实际提速幅度。

# Windows 本地商品工作台

## 启动

安装 Python 3.10 或更新版本（勾选 Add Python to PATH），在项目根目录双击 `启动工具.bat`。
首次启动自动创建 `.venv`，安装 `webapp/requirements.txt` 和 Playwright Chromium，需要网络。
服务固定监听 `127.0.0.1:8765`，健康检查成功后打开浏览器。关闭终端或 Ctrl+C 停止服务。
如果浏览器没有自动打开，可手动访问 `http://127.0.0.1:8765`；端口占用、安装失败等会在终端显示。
不要将本服务改成公网监听或经反向代理公开。

## 使用

1. 平台账号 → 打开登录窗口 → 在本机浏览器扫码/完成验证。
2. 商品采集 → 输入逗号分隔关键词、平台和页数 → 开始采集。
3. 进度显示实际完成的关键词/平台工作单元，不代表页内进度。原爬虫没有页级进度接口。
4. 每次采集结果按平台和商品 ID 更新，自动保存主图。失败记录可在图片管理筛选后选择重试。
5. 商品卡片/表格支持当前页全选、跨页选择（筛选时清空选择）、下载选中、CSV/ZIP 导出。
6. 加入待发布后编辑独立草稿，再在发布中心选择平台和校验资料。

图片仅主图。SKU/详情图没有数据来源，明确标记待支持。图片 CDN 白名单为 alicdn.com、tbcdn.cn、taobaocdn.com；未知域名下载失败会记录原因，不会放开任意 URL。
下载限制 15 MB、2500 万像素、20 秒网络超时和 45 秒读取总时限；停止图片任务会等待当前网络阻塞返回（一般最多 20 秒）。
图片按平台/安全处理后的关键词/商品 ID/内容哈希保存。相同内容不会重复覆盖；不同商品目录保留各自文件。
CSV 做公式转义；ZIP 包含选中记录的 CSV 和已下载图片，未下载或失败图片不会伪造。
删除商品记录保留下载文件和独立草稿，以免误删已用于发布准备的资料。

## 数据和隐私

默认存储 `data/webapp/products.db` 和 `data/webapp/images/`；可用 `PRODUCT_TOOL_DATA` 环境变量指定其他目录。
关闭服务后复制整个数据目录可备份。账号文件仍存放在原 `state/`，不通过 Web 暴露。
Web 调用禁用爬虫原始日志/页面 dump，避免登录信息或会话 URL 写入普通日志。原 CLI 行为保持原样。
账号“已保存本地状态”不代表平台确认登录有效；实际采集可能要求重新登录、人工验证或被平台限制。

## 发布扩展

`publishers.py` 定义 Draft、TaobaoPublisher、XianyuPublisher、XiaohongshuPublisher。
统一字段：标题、描述、售价、分类、库存、SKU、图片、物流、目标平台、平台专属字段。
所有适配器均明确为“暂不支持 / 需要官方授权”，真实发布端点返回 409。
当前校验只验证基础草稿，不宣称符合各平台最终官方字段规范。
接入官方 API 时须补齐授权、平台字段规范、人工确认、结果持久化和失败处理，再启用发布。

## 验证

`python -m pip install pytest httpx`

`python -m pytest webapp/tests -q`

已验证 API、SQLite、模拟图片下载及导出、子进程取消、无登录失败、草稿校验。模拟数据仅在临时测试目录产生，生产没有演示结果注入接口。
Linux 系统 Chromium 验证桌面和窄屏页面、批量选择、下载、CSV/ZIP、分页、草稿编辑及导航。
当前环境未实测 Windows 批处理运行和淘宝/闲鱼账号真实登录采集，不把模拟测试当作平台采集成功。

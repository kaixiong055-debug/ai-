# 本地商品管理实施计划

已确认方案：FastAPI + 原生页面 + SQLite + 独立爬虫进程。

- [x] 存储和安全下载：平台/ID 唯一；图片仅 HTTPS 公网白名单 CDN，禁止重定向，验证解码、大小、哈希；测试去重、危险 URL、CSV、ZIP。
- [x] 任务与账号：逐关键词/平台调用现有程序，独立报告目录，真实完成数，终止进程树；登录助手只暴露摘要。测试失败、取消和恢复。
- [x] 草稿与发布：统一字段，三独立适配器，只校验并报告未授权，不执行发布。
- [x] 原生中文页面：八导航、筛选分页、卡片表格、选择下载导出、任务与草稿编辑；浏览器验证。
- [x] Windows 启动：检查 Python、虚拟环境、依赖与浏览器，监听回环地址，就绪后打开页面；文档记录实测范围。

审查重点：凭据不泄露、SSRF、跨站请求、重复商品、取消后的进程残留。
原爬虫 CLI 保持不变。只检查实现直接依赖的文件。

验证记录：19 项 pytest 通过；系统 Chromium 桌面 1440×1000、窄屏 390×844 交互检查通过，控制台无错误。原 CLI --help 通过，原爬虫及登录助手无改动。Windows 批处理和真实账号平台采集未实测。
审查修复：自动主图下载、读取总时限和取消检查、逐图 HTTP 失败记录、磁盘 ZIP、草稿平台校验。

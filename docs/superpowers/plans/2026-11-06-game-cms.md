# Game CMS Implementation Plan

> 执行方式：按模块并行实现，统一接口，最后集成测试与独立审查。

**Goal:** 可部署 Java 管理系统与独立 SEO 游戏页。
**Architecture:** Spring Boot+JDBC+Thymeleaf；H2默认，PostgreSQL可配；本地服务端图片和视频直链。
**Tech Stack:** Java17+, Maven, Spring Boot3, Spring Security, Thymeleaf, 原生JS。
**Spec:** docs/superpowers/specs/2026-11-06-game-cms-design.md

## Global Constraints
- 新分支，不修改旧爬虫；保留获认可视觉；手机和微信webview适配。
- 后台有认证和CSRF，外链HTTPS，文本转义，导入不暴露渠道私有字段。
- 所有游戏唯一SSR页，默认SEO可覆盖，草稿不公开，生产域名独立配置。

## Review Focus
- 未登录写API与跨站请求不能更改内容。
- 上传/ZIP路径穿越、体积和伪装格式不能写任意文件。
- 同时编辑revision冲突不能默默覆盖。
- 下线/删除游戏后不可继续公开或留在站点地图。
- 自定义SEO/JSON-LD不引入脚本，素材缺失可编辑而不伪造。

- [x] 2 前台：PublicController/SeoService/templates/site/static/site；保留现有CSS，SSR SEO、首页搜索、404、预览、sitemap/robots；MockMvc验证正文与SEO。

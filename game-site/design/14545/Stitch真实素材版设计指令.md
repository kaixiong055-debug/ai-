# 使用真实素材重做：小小驯龙师手机详情页

这次仅设计一款游戏的手机详情页（390px宽），先不要继续做“合规名录”或后台式页面。

## 目标

读者从搜索引擎进入后，先被游戏画面吸引，再理解玩法，最后自主选择下载或查看介绍。这是面向玩家的游戏推广页面，不是数据核验工具。技术要求放在设计注释中，不展示给玩家。

## 必须使用的真实素材

- 首屏主视觉：游戏素材/banner/001.jpg，1008×567，16:9。保留原图主体与原有文字，不拉伸，不在它上面堆多层新文案。
- 图标：游戏素材/游戏icon/001.jpg，256×256。
- 五张宣传截图：游戏素材/游戏截图/001.jpg 至 005.jpg，均608×1080。它们包含宣传文字与角色插画，标为“游戏画面”，不冒充本站实测截图。
- 宣传视频：横屏1920×1080，约20秒。用清晰封面和播放按钮，用户点击后才加载视频。
- 试玩视频：竖屏1080×1920，约122秒。作为“更多视频”，不抢占主操作。
- 相同的002图标、002横幅是重复素材，不要展示成两套图。

## 首屏排版，按此优先级

顶部简短导航 → 真实16:9宣传横幅 → 图标与“小小驯龙师”标题 → 完整渠道名称作为小字 → “恐龙收集 / 竖版 / 放置闯关”等有来源的标签 → 一句玩法说明 → 明确的“下载游戏”主按钮与“查看游戏介绍”次按钮。

一句玩法说明：收集并培养远古恐龙，搭配阵容，开启放置闯关之旅。

首屏应像一个让人愿意继续浏览的游戏页面，不是表格。游戏ID14545只供数据关联，不用放在醒目位置。安卓版版本字段为1.0.0，不要自行改成2.0.4。暂时不要绘制“iOS下载”或“在线玩”按钮，因为当前尚未核验对应入口与状态枚举。

## 往下浏览

1. 游戏画面：五张竖图按001到005自然排序，横向滑动、可点开查看。卡片宽度让用户看出下一张，保留图中原有文字，不再次覆盖标题。
2. 宣传视频：用户主动播放。视频和截图不自动轮播。
3. 玩法介绍：恐龙收集培养、阵容搭配、基因与进化，配简短说明。使用提供的简介和图片，不添编PVP排名、跨端互通、开服人数等内容。
4. 福利说明：七日签到孵化卡、素材标注的千抽福利、首充霸王龙。区分需要首充的内容；活动条件以游戏内说明为准。没有礼包码，不画一键复制兑换码组件。横幅上的648代金宣传没有完整规则，不另做“立即领648元”按钮。
5. 游戏介绍正文与版本：有清晰H2的小段文字，帮助读者了解游戏，也支持后续SEO。不要把文案全部画进图片。
6. 下载与常见问题：在有事实依据时说明版本和入口；微信下载限制只有实际需要时才提示，不把长篇技术说明摆在中间。
7. 页尾简洁推广说明与返回列表链接。无虚构评论、评分或下载量。

## 视觉

以原图蓝紫色夜景、明亮卡通恐龙为视觉中心，搭配暖白阅读区域与橙色主按钮。轻松、有游戏氛围，同时保证正文易读。减少分割线和连续小卡片，不需要“档案馆”式结构。手机底部保留清楚的游戏名称和一个主要操作，避开底部安全区，不遮挡正文。

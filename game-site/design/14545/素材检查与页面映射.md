# 素材包检查与自动识别规则

本次已实际检查一个样本：小小驯龙师-首充送霸王龙，JSON game_id=14545。

| 原始输入 | 页面用途 |
|---|---|
| 一句话介绍.txt | 简介素材；语言不通顺时仅依据原意整理，不添加事实 |
| 游戏简介.txt | 游戏介绍、玩法正文与SEO描述来源 |
| 游戏上线福利.txt | 福利区，有什么写什么；不派生未提供的礼包码 |
| 游戏首发时间及类型.txt | 素材所述名称、日期和分类标签 |
| 游戏素材/游戏icon/ | 图标；以文件内容哈希去重 |
| 游戏素材/banner/ | 首屏宣传横幅；本例1008×567 |
| 游戏素材/游戏截图/ | 画廊；按文件名数字排序，本例5张608×1080宣传截图 |
| 文件名含宣传的视频 | 主视频；本例约20秒横屏 |
| 文件名含试玩的视频 | 补充视频；本例约122秒竖屏 |
| JSON游戏字段 | ID、名称、版本、原始推广链接与状态来源 |

## 已确认的重复素材

icon/001.jpg与002.jpg完全相同；banner/001.jpg与002.jpg完全相同。共9个图片文件，去重后7张，不把重复内容展示两次。

## 数据边界

- JSON与素材包匹配的是14545，不是此前示意稿中的14605。
- 原始ZIP中没有额外的“操作指令”需要执行；文字文件只按产品文案读取。
- 当前确认了这一种包结构，后续同结构可沿用映射；目录变化、缺文件、多视频或同名冲突需要生成明确报告，不能静默猜测。
- 主介绍、福利和标签来自资料，不等于实际游玩或活动领取已验证。
- 不能因ZIP含“在线玩”标签或JSON出现h5对象，就创建一个没有真实目标的在线玩按钮。
- 不把佣金字段、渠道账号标识或素材签名链接放到玩家页面。

当前交付为素材检查、清洗后的页面数据样例与Stitch真实素材版设计指令；没有声称已在Stitch生成页面，也未编写完整网站。
